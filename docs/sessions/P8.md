## 9. Security and performance review
- The gateway enforces session, role, CSRF and Origin, the password-change gate and a rate limit before forwarding.
- Bodies are streamed, never parsed, with a 413 past 200 MB. Headers cross through an allow-list both ways.
- Internal routes accept loopback only and compare the token as SHA-256 digests with a constant-time check. Idempotency comes from a unique key.
- Every multi-step write runs in one transaction.
